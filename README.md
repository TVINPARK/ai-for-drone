# 🚀 ТВ-телеметрия Квадросима

Система автоматической телеметрии для симуляторов гоночных дронов. Захватывает HUD с экрана, распознаёт телеметрические данные через OCR, детектирует положение стиков и строит подробные аналитические отчёты.

## 📋 Требования

- **ОС:** Windows 10/11 (Linux/macOS с ограничениями через mss)
- **Python:** 3.10+
- **Экран:** 1920×1080 (рекомендуется)
- **GPU:** Опционально для dxcam (Windows)

---

## 🛠️ Установка

```bash
pip install -r requirements.txt
```

**Важно:** При первом запуске EasyOCR загрузит модели (~200 МБ) для русского и английского языков.

### Зависимости

- `numpy >= 1.24`
- `opencv-python >= 4.8`
- `mss >= 9.0` (кроссплатформенный захват)
- `dxcam >= 0.0.5` (только Windows, GPU-ускорение)
- `pandas >= 2.0`
- `plotly >= 5.18`
- `easyocr >= 1.7.0` (основной OCR)
- `scipy >= 1.10`
- `Pillow >= 9.0`

## ⚙️ Настройка и калибровка

### GUI-калибратор (рекомендуется)

```bash
python -m qt.capture.gui_calibrator
```

Откроется окно со скриншотом: перетаскивайте рамки зон HUD, сохраняйте в `config.json`.

### Консольная калибровка

```bash
python -m qt.capture.calibrate
```

### Автоматическая калибровка

При запуске система пытается автоматически определить зоны HUD для разрешения 1920×1080.

## 🏁 Запуск

### Лаунчер (рекомендуется)

```bash
python launcher.py
```

**Ключи лаунчера:**
- `--help` — справка
- `--auto` — автоматический режим
- `--skip-deps` — пропустить проверку зависимостей

### Прямой запуск

```bash
python main.py [-c CONFIG] [-t TIME] [--calibrate]
```

**Аргументы:**
- `-c, --config` — путь к config.json (по умолчанию `config.json`)
- `-t, --time` — лимит записи в секундах
- `--calibrate` — режим калибровки ROI

### EXE-файл (для пользователей Windows)

```bash
python build_exe.py
```

Готовый файл: `dist/QuadrosimTelemetry.exe`

## 📊 Как это работает

1. **Захват экрана:** DxCam (Windows, GPU) или mss (кроссплатформенно)
2. **OCR:** EasyOCR распознаёт текст из зон HUD
3. **Стики:** Детекция цветных точек на виртуальных стиках
4. **Логирование:** SQLite с буферизацией (сессии, круги, кадры)
5. **События:** Детекция взлёта, посадки, крашей, кругов
6. **Отчёт:** HTML с графиками телеметрии, секторами, дельтой и метриками стиков

После посадки/краша в папке `reports` появляется HTML-отчёт.

## 🔍 Распознаваемые данные HUD

| Поле | Описание | Формат |
|------|----------|--------|
| pilot | Имя пилота | Кириллица |
| datetime | Дата и время | — |
| battery | Заряд батареи | V, A |
| mode | Режим полёта | ACRO/HORIZON/ANGLE |
| limit | Лимит времени | мм:сс |
| speed | Скорость | км/ч |
| alt | Высота | м |
| laps | Счётчик кругов | X/Y |
| cur_time | Время текущего круга | чч:мм:сс.мс |
| best_time | Лучшее время круга | чч:мм:сс.мс |

## 📝 Примечания

- DxCam требует Windows 8+ и Desktop Duplication API
- При exclusive fullscreen возможны чёрные кадры — используйте borderless window
- Точность OCR зависит от контраста и шрифта в HUD симулятора

---

## 🛠️ Разработка

Основные модули для расширения:

- **qt/ocr/engine.py** — бэкенд OCR (EasyOCR)
- **qt/ocr/digits.py** — шаблонное распознавание цифр
- **qt/sticks/detector.py** — детекция положения стиков
- **qt/events/__init__.py** — машина состояний полёта
- **qt/analysis/** — анализ данных (круги, сектора, дельта, стики)
- **qt/report/html.py** — генерация HTML-отчётов с Plotly

---

## 📄 Лицензия

Проект использует open-source библиотеки: numpy, opencv-python, pandas, plotly, mss, dxcam, easyocr, scipy, Pillow.
